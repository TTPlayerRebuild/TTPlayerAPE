## 测试中修正的问题

1. 修正标签对象和输入流的释放顺序；顺序错误时原版 Set 返回成功，但读取锁阻止最终保存。
2. Encoder 同样在释放标签对象前释放输出流，保证原版宿主可重新打开输出文件。
3. float64 半整数改为原版的最近偶数舍入；没有用简单加 0.5 截断代替。
4. ABI 的码率单位保持 bit/s，而 SDK 返回 kbit/s。
5. APL 的二进制尾部标签不参与文本编码判断，避免 UTF-8 中文路径被误当作 ANSI。
6. 测试工具增加实际标签和 PCM 检查；修正窗口识别，避免匹配主窗体上碰巧同 ID 的控件。
