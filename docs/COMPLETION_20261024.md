# ttp_ape 后续补全与验收

日期：2026-10-24。发行版本：`2026.10.24`。

## 修改

从嵌入 WAV／RF64 fmt 信息保留声道掩码、有效位数；多声道返回 WAVEFORMATEXTENSIBLE。增加可选 MetadataCommit 代理，关闭自身解码文件句柄后委托宿主提交。

## 验证

原接口、不支持提交扩展、提交成功、磁盘满和重复提交模式在三系统通过；既有 12 秒样本在原版／重建版实际播放通过。

Windows 11、XP SP3 x86、Win7 SP1 的组合回归各 33 项通过，其中 19 组 PCM 样本数及校验相同。这是组合测试数量，不代表本插件单独具有 33 个独立用例。Win11 按用户要求代为现代 Windows 验证，无独立 Win10 实测。

## 保留边界

提交扩展只有宿主支持时才公开。原版保留最后释放保存；没有嵌入布局的文件不猜测布局。不是全部历史 SDK 文件的位精确验证。
